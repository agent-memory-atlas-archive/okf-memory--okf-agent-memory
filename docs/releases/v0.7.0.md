# Release v0.7.0: Bundle Quality Scorecards & Pre-Pull Quality Gating

Release `v0.7.0` introduces OpenSSF-inspired **Bundle Quality Scorecards** (Phase 21), deterministic pre-pull quality gating (`--min-score`) with atomic filesystem rollback, machine-readable Scorecard telemetry in `okf validate --json`, and duplicate-safe ISO date log mutations.

---

### 1. Key Highlights & Features

#### Open Knowledge Quality Scorecards (`pkg/okf/scorecard.go`)
* **Objective Quality Evaluation:** Implements deterministic, reproducible quality evaluation (scores 0–100 and letter grades A through F) for decentralized OKF agent memory bundles without external network calls or tracking.
* **Three Weighted Quality Pillars:**
  1. **Epistemic Maintenance (35% Weight):** Evaluates freshness horizons and active concept lifecycles via `stale_after: YYYY-MM-DD`. Concepts are penalized proportionally if allowed to expire without review.
  2. **Human Stewardship (35% Weight):** Verifies human maintainer accountability (`verified.by: human/<handle>`) to protect autonomous AI coding agents from recursive synthetic hallucinations.
  3. **Conformance Integrity (30% Weight):** Strict DAG validation under OKF v0.2 §5 & §7. Broken markdown links are penalized -50% each; unindexed or orphaned concepts are penalized -30% each.
* **CLI Inspection:**
  ```bash
  okf validate . --scorecard
  ```
  Emits formatted scorecard telemetry with grade, score breakdown, and human-readable signals.

#### Pre-Pull Quality Gating with Atomic Rollback (`okf pull`, `okf restore`)
* **Policy Enforcement at Pull Time:** Added `--min-score <N>` to `okf pull` and `okf restore`:
  ```bash
  okf pull github.com/okf-memory/jwt --min-score 80
  okf restore --min-score 85
  ```
* **Atomic Safety:** The bundle archive is unpacked into an isolated temporary directory and strictly validated against the required quality threshold before copying into `.okf/vendor/` or updating `okf.lock`. If validation or score checks fail, the transaction rolls back cleanly without leaving orphaned files.

#### Machine-Readable Scorecard JSON Telemetry
* Enhanced `okf validate --scorecard --json` to include structured `scorecard` payloads:
  ```json
  {
    "scorecard": {
      "score": 100,
      "grade": "A",
      "maintenance": 100,
      "stewardship": 100,
      "integrity": 100,
      "signals": [
        "all 4 concept(s) active and current (4 durable invariants)",
        "100% human stewardship (4/4 verified or authored by humans)",
        "strict conformance passed: 0 broken links, 0 orphans, valid DAG"
      ],
      "summary": "Quality Scorecard: Grade A (Score: 100/100) — M:100% S:100% I:100%"
    }
  }
  ```

#### Mutation Bookkeeping Hygiene
* **Same-Day Log Entry Deduplication:** Sanitized `pkg/okf/mutate.go` so mutations on the same calendar day append under existing `## YYYY-MM-DD` headings rather than creating duplicate date sections in `log.md`.
